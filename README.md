# Stance Health Appointment Page

A responsive recreation of the Stance Health appointment booking page.

## Features

- Responsive appointment booking UI
- Phone number validation
- First name validation
- Email validation
- Gender selection
- Date of Birth field
- Bio / Notes field
- Google Sheets integration
- Google Apps Script backend
- Vercel deployment ready

## Technologies

- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Sheets

## Google Sheets Integration

The appointment form sends submitted details to a Google Apps Script Web App, which stores the submitted appointment details in Google Sheets.

## Deployment

The project can be deployed using Vercel as a static website.
